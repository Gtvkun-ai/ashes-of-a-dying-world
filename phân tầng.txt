PHAN TANG VA VI TRI CAC THANH PHAN TRONG DO AN

1. Vi tri tong the trong project

Root:
- `project.godot`: cau hinh project Godot, main scene, autoload.
- `Ashes of a Dying World.sln` / `.csproj`: solution va project C#.
- `src/`: code chinh tu viet.
- `scenes/`: scene world/ui.
- `assets/`: sprite, shader, resource data, character config, weapon config.
- `addons/`: plugin/addon ngoai, hien tai co `dialogic`.

3. Phan tang kien truc

Tang 1 - Cau hinh va tai nguyen
- Vi tri:
  - `project.godot`
  - `assets/resources/...`
  - `assets/sprites/...`
  - `assets/shader/...`
- Vai tro:
  - Luu config game, resource nhan vat, vu khi, race, icon, body scene.
- Day la tang du lieu nen, khong chua logic gameplay chinh.

Tang 2 - Data model / Domain data
- Vi tri:
  - `src/Core/Data/`
  - `src/Core/Save/SaveGameData.cs`
- Vai tro:
  - Dinh nghia du lieu cot loi:
	- stat
	- race
	- skill
	- equipment
	- save data
- Day la tang mo ta "game co gi".

Tang 3 - Manager / He thong nen
- Vi tri:
  - `src/Core/Managers/`
- Vai tro:
  - Dieu phoi luong game:
	- `SceneManager`: doi scene, spawn, camera, HUD world
	- `SaveManager`: save/load
	- `PlayerManager`: party, active character
	- `InventoryManager`: tui do
- Day la tang he thong, dung o giua data va gameplay.

Tang 4 - Gameplay actor / Entity
- Vi tri:
  - `src/Entities/`
  - `scenes/world/WhisperingFields/Slime1.cs`
- Vai tro:
  - Chua logic cua nhan vat va quai:
	- player
	- npc companion
	- slime
- Day la tang "vat the song" trong game.

Tang 5 - World / Map interaction
- Vi tri:
  - `src/World/`
  - mot phan script trong `scenes/world/WhisperingFields/`
- Vai tro:
  - Quan ly level, spawn point, trigger doi scene, vung tim quai, vung attack.
- Day la tang ket noi entity voi ban do.

Tang 6 - Presentation / UI
- Vi tri:
  - `src/UI/`
  - `scenes/ui/`
- Vai tro:
  - Hien thi thong tin va tuong tac menu:
	- HUD party
	- HUD tung nhan vat
	- detail panel
	- inventory panel
	- menu button
	- damage number
	- enemy HP bar

Tang 7 - Entry scene / Dieu huong ban dau
- Vi tri:
  - `scenes/main/screen_main.tscn`
  - `src/Scenes/ScreenMain.cs`
- Vai tro:
  - Diem vao game.
  - Tao world dau tien.
  - Tao player.
  - Chuyen tu menu sang gameplay.

4. Quan he phu thuoc giua cac tang

Huong phu thuoc chinh:
- Tai nguyen -> Data -> Manager -> Entity/World -> UI/Scene

Chi tiet:
- `assets/resources/...` duoc nap boi `CharacterConfig`, `EquipmentItemData`, `RaceData`.
- `PlayerStats` doc `CharacterConfig`, `RaceData`, `EquipmentManager`.
- `Player` su dung:
  - `PlayerStats`
  - `InventoryManager`
  - `EquipmentManager`
  - `SkillData`
- `NpcCharacter` ke thua `Player`.
- `HyouAI` dieu khien `NpcCharacter/Player`.
- `SceneManager` thao tac voi:
  - `Player`
  - `GameLevel`
  - `SpawnPoint`
  - UI overlay
- UI lay du lieu tu:
  - `PlayerManager`
  - `PlayerStats`
  - `InventoryManager`
  - `EquipmentManager`
  - `Player`

7. Tom tat ngan gon

Do an nay duoc phan tang kha ro:
- `assets/` va `project.godot`: tai nguyen + cau hinh
- `src/Core`: du lieu va manager
- `src/Entities`: nhan vat va AI
- `src/World`: logic map/chuyen scene
- `src/UI`: giao dien
- `src/Scenes`: diem vao gameplay
- `scenes/`: cac scene Godot de gan voi code

Neu nhin theo "vi tri", phan quan trong nhat hien tai nam o:
- `src/Core`
- `src/Entities`
- `src/UI/HUD`
- `scenes/world/WhisperingFields`
